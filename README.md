# High-Performance Course Detail Page

This project is a technical assessment focused on SEO optimization, Performance (Lighthouse 90+), and Server-Side Rendering.

## 🚀 Key Features & Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS / SCSS
- **SEO:** Dynamic Metadata API, Open Graph tags
- **Structured Data:** JSON-LD (Course Schema)
- **Performance:** Optimized with `next/image` (LCP priority)

## 🛠 Performance Optimizations

- **Image Optimization:** Used `sizes` attribute to serve scaled images for mobile devices.
- **SSR & Streaming:** Implemented server-side rendering for instant content delivery.

## 🚦 Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
4. Build for production: `npm run build && npm run start`
